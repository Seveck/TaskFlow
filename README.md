# ⚡ TaskFlow

> Gestor ligero de tareas y productividad con arquitectura modular y buenas prácticas de desarrollo.

---

## 📌 Convención de Commits

Este proyecto sigue el estándar **[Conventional Commits](https://www.conventionalcommits.org/)**:

- `chore:` Tareas de configuración, herramientas o mantenimiento.
- `docs:` Cambios exclusivos en la documentación.
- `feat:` Nuevas funcionalidades para el usuario.
- `test:` Inclusión o corrección de pruebas unitarias.
- `fix:` Corrección de errores o validaciones de negocio.
- `refactor:` Mejoras en la estructura del código sin cambiar su comportamiento.

---

## 🚀 Instalación y Uso

```bash
# Clonar el repositorio
git clone https://github.com/Seveck/TaskFlow.git
```
